# 串口终端视图使用指南

本文档介绍串口工作台中的日志视图和终端视图，以及终端模式下的常用交互方式。

## 数据源连接

串口工作台支持四种数据源：

- `本地串口`：选择系统串口并配置波特率等参数。USB 串口插入或拔出后，端口列表会自动刷新；也可以随时点击刷新按钮手动更新。
- `TCP 远程串口`：填写远端主机和端口，适合 ser2net、ESP-Link 等桥接设备。
- `UDP 数据接口`：填写本地绑定地址/端口和远端地址/端口。连接后可继续使用日志、终端、发送、统计和图表功能；UDP 不建立会话，“已连接”表示本地端口已绑定且远端地址配置成功。
- `模拟数据`：由应用在本机生成 JSON 测试数据，不需要连接硬件，适合检查原始日志、数据解析、波形和控制面板。

本地串口读取失败时，应用会释放失效的系统句柄并显示断开状态。ESP32-S3/C3 等原生 USB 设备复位时可能在 Windows 中短暂移除并重新创建 COM 口；需要自动恢复接收时，可在本地串口高级设置中启用 `断线自动重连`。未启用时，设备重新出现后手动点击连接即可。

### 使用模拟数据

在数据源列表底部选择 `模拟数据`，选择信号预设并点击 `启动模拟`：

- `通用波形`：支持正弦波、方波、三角波、锯齿波、随机噪声和固定值，输出 `ch1` 至 `ch8`。
- `XY 轨迹`：支持圆形和李萨如曲线，输出 `x`、`y`，可直接用于 XY 二维曲线。
- `IMU 三轴姿态`：输出 `roll/pitch/yaw`（°），用于 IMU 3D 姿态的欧拉角直驱模式。
- `IMU 六轴`：输出 `ax/ay/az`（g）和 `gx/gy/gz`（°/s），可用于 IMU 3D 姿态的原始六轴融合模式。

三种预设都可以调整采样率、信号或运动频率和噪声强度；通用波形与 XY 轨迹还可以调整幅值和偏移。模拟数据按配置的采样率生成时间戳和信号相位，界面短暂繁忙时会把欠缺样本合批补齐。数据以每行一个 JSON 对象的形式进入，与真实数据共用接收、分帧、统计和图表解析链路。在右侧 `数据` 页选择 JSON 并应用对应字段，即可驱动曲线、接收数值、状态灯和 IMU 控件。

模拟模式下发送内容只会记为本地 TX，用于检查发送格式和控制面板命令，不会转发到任何设备。

## 1. 视图切换

连接串口并开始接收后，可在串口工具栏的 `日志` / `终端` 按钮之间切换：

- `日志`：适合查看结构化输出、按 `RX/TX` 分流、搜索关键字、切换文本/HEX 和导出日志
- `终端`：适合设备 CLI、Bootloader 命令台、AT 命令和串口 shell 这类持续交互式会话

## 2. 日志视图

日志视图延续原有串口查看能力：

- 支持毫秒级接收时间戳；高频数据按底层读取时间记录，避免应用合批统一成同一时间
- 支持 `RX/TX` 前缀
- 支持收发分屏
- 支持文本 / HEX 模式切换
- 支持颜色标记、波形 / FFT 和日志导出

时间戳、收发分屏和导出等选项位于串口工具栏右侧的 `更多` 菜单。接收与发送的文本/HEX 格式集中在底部发送栏左侧，入口会直接显示当前状态，例如 `收 HEX · 发 文本`。

### 2.1 自定义时间戳

在 `更多 → 查看` 中启用 `时间戳` 后，可选择年月日、时分秒、分秒等预设，也可以直接填写格式串。支持以下本地时间占位符：

| 占位符 | 含义   | 示例 |
| ------ | ------ | ---- |
| `YYYY` | 四位年 | 2026 |
| `MM`   | 月     | 07   |
| `DD`   | 日     | 24   |
| `HH`   | 时     | 15   |
| `mm`   | 分     | 44   |
| `ss`   | 秒     | 34   |
| `SSS`  | 毫秒   | 123  |

例如 `YYYY年MM月DD日 HH:mm:ss` 会显示为 `2026年07月24日 15:44:34`，`mm:ss` 只显示分秒。界面会实时预览结果，并保存是否显示及自定义格式。日志显示、带时间戳复制和 TXT 导出使用同一格式；CSV 继续保存标准 ISO 时间，便于程序读取。

### 2.2 复制日志行

为了避免误把时间戳和 `【RX】/【TX】` 前缀粘到命令行或文档里，日志视图默认把这些前缀设为不可选中——直接框选只会得到正文。需要带元信息时可按下面三种方式分别取用：

| 操作                  | 复制内容                                                         | 适用场景                        |
| --------------------- | ---------------------------------------------------------------- | ------------------------------- |
| 选中 + `Ctrl+C`       | 选中的纯文本（不含时间戳与方向前缀）                             | 复制设备输出去运行 / 粘到代码里 |
| 选中 + `Ctrl+Shift+C` | 选中行的完整内容：`[时间戳] 【RX/TX】 正文`                      | 上报 issue、对照时间分析        |
| 右键选中内容或日志行  | 弹出菜单，可在「纯文本 / 含时间戳 / 含时间戳+RX/TX」三种模式中选 | 临时切换、不想记快捷键          |

注意事项：

- `Ctrl+Shift+C` 和右键菜单中的「含时间戳」「完整」两项会按行扩展——即使你只选了一行的半截，复制出来的也是该行的整行内容，并按你选中的行范围依次拼接。
- 「纯文本」模式严格按照你实际框选的字符复制，可以只复制一行的一部分。
- 点击日志视图后，`Ctrl+A` 只会全选当前日志视图，不会选中工具栏或侧栏；右键未选中的日志行会直接选中该行。
- 复制成功后会清除当前选区，避免高亮长期遮挡日志内容。
- 桌面应用通过系统剪贴板写入普通文本；Windows 已开启剪贴板历史时，未超过系统单条大小限制的内容可在 `Win+V` 中查看。
- 复制成功后会在底部 `输出日志` 中提示行数；若浏览器拒绝写剪贴板，会以 `warn` 级别记录在同一日志区。

### 2.3 保存当前窗口

在日志视图中右键并选择 `保存当前窗口全部内容为 TXT`，可保存当前通道、收发方向和搜索条件下显示的全部行，不受虚拟滚动范围影响。终端视图也支持相同的右键保存操作。

### 2.4 使用 JustFloat / VOFA RawData 波形

串口工作台支持解析 VOFA JustFloat 二进制数据：每帧由若干个 little-endian `float32` 数值组成，并以 `00 00 80 7F` 结束。本地串口、TCP 和 UDP 数据源均可使用。

1. 连接数据源并开始接收。
2. 点击串口工具栏中的图表视图或分屏视图按钮。
3. 打开右侧 `数据` 页。
4. 把解析模式设为 `JustFloat / VOFA RawData`，确认通道预览后点击 `应用解析`。
5. 根据需要在波形工具栏中切换 `时域` 或 `FFT`。

通道列表留空时，如果接收缓冲区已有完整帧，打开右侧 `数据` 页就会预建 `ch1`、`ch2` 等通道；否则会在收到首个有效帧后自动生成。也可以在高级图表配置中提前添加通道，并用从 `0` 开始的“浮点序号”指定该通道读取帧内第几个数值。

使用 UDP 时，上位机的本地端口应与设备的目标端口一致；“远端地址”应填写设备或 WiFi 模块的实际 IP，“远端端口”应填写设备的本地端口。由于 UDP 不建立会话，界面显示“已连接”只表示本地绑定成功，不代表设备已经发出数据。

### 2.5 使用 Modbus 寄存器波形

串口工作台可以作为只读 Modbus 主站，支持 RTU、ASCII 和原生 TCP，读取保持寄存器或输入寄存器并直接绘图：

1. RTU 或 ASCII 使用本地串口，也可以连接相应的原始字节透明网关；原生 Modbus TCP 需先选择 TCP 数据源。
2. 打开右侧 `数据` 页，选择 `Modbus RTU`、`Modbus ASCII` 或 `Modbus TCP`。
3. 填写从站地址或单元标识、功能码 `03/04`、零基起始地址、寄存器数量和轮询周期。
4. 按需关闭 `自动轮询`；关闭后应用只解析收到的响应，不主动发送请求。
5. 选择数值类型、字节序、字序、比例和偏移，点击 `应用解析`。
6. 打开图表或分屏即可查看 `reg<地址>` 通道。

每个有效响应生成一个包含全部寄存器值的同步采样点，因此现有波形、滤波、FFT、控制面板和导出功能都能直接使用。32 位数据每个值占两个寄存器；当前一个读取块共用同一种数值布局。完整的地址、字节序和支持范围说明见[输入数据解析格式](DATA_FORMAT_GUIDE.md#modbus-rtu)。

### 2.6 使用通用二进制协议

设备输出自定义二进制帧时，可以通过协议设计器配置帧头、长度字段、TYPE 消息、Payload 字段和 CRC，不需要修改上位机解析代码：

1. 打开右侧 `数据` 页，选择 `通用二进制协议`。
2. 点击 `打开协议设计器`。
3. 在 `帧结构` 中选择固定长度、长度字段或帧尾分隔符，并配置最大帧长和 Payload 起始偏移。
4. 按需选择 CRC 或校验和预设，确认校验值位置和覆盖范围。
5. 在 `消息字段` 中添加 TYPE 匹配规则及数值字段。
6. 在 `实时预览` 中粘贴一帧真实 HEX 数据，确认字段值后应用协议和数据解析。

字段 key 会直接成为图表和控制面板可绑定的通道。协议 JSON 可以从设计器导出并在其他设备或电脑上导入。完整配置说明见[通用二进制协议](DATA_FORMAT_GUIDE.md#binary)。

### 2.7 折叠原始数据

使用上下分屏观察波形时，可以点击原始串口数据标题栏中的 `折叠`：

- 原始数据区会缩成一条状态栏，波形自动占用释放出来的空间
- 状态栏继续显示接收状态和累计行数，不会停止后台接收
- 点击状态栏中的 `展开` 可以恢复原始数据区
- 底部发送栏不会随原始数据区折叠，仍可继续向设备发送命令
  日志模式的折叠入口用于“日志 + 上下分屏”布局。

### 2.8 快捷控制面板

点击左侧 `面板` 进入独立控制面板工作台，可以把常用发送命令配置成可重复操作的控件。选择串口来源后，控制面板直接继承串口工作台已有的连接、发送和数据解析设置。

1. 点击 `编辑`，从左侧组件库把发送按钮、开关、滑块、参数输入、参数微调、摇杆、命令序列、串口日志、数据显示或可视化组件拖入中间画布；也可以直接点击组件添加。
2. 拖动组件标题左侧的手柄，可把组件自由移动到画布任意位置；拖动右下角缩放手柄可连续调整宽高，不会吸附网格。选中组件后，可在悬浮属性面板精确修改 X/Y 坐标、宽度和高度。
3. 顶部选择数据来源；点击 `前往设置` 会弹出该来源已有的连接和数据配置，关闭后立即生效。
4. 滑块和参数输入使用 `{value}` 作为当前值占位符，例如 `PWM={value}`；文本控件沿用全局编码与换行符，HEX 控件直接发送十六进制字节。
5. 点击 `运行` 隐藏组件库并锁定布局，然后直接操作控件发送命令。

#### 数据解析和输入格式

设备应当按行输出数据。应用先把每一行解析为若干数值通道，再由波形、接收数值、状态灯和 IMU 等组件绑定通道。`数据解析` 中预览出来的字段名，就是组件属性中需要填写的通道 key。

下面几种文本格式都可以直接使用：

```text
JSON：     {"temp":25.3,"voltage":3.3}
KV：       temp=25.3,voltage=3.3
分隔符：   25.3,3.3
正则样本： temp:25.3
正则表达式：temp:(?<temp>-?\d+(?:\.\d+)?)
```

- JSON 和 KV 会使用字段名作为通道 key，例如 `temp`、`voltage`。
- 分隔符模式按列生成或绑定通道；确认预览后，可以在通道配置中修改名称。
- 正则模式必须使用命名捕获组，组名会成为通道 key。
- JustFloat / VOFA RawData 是二进制格式，每帧由 little-endian `float32` 数值和结尾标记 `00 00 80 7F` 组成，详细步骤见 [2.4 使用 JustFloat / VOFA RawData 波形](#24-使用-justfloat--vofa-rawdata-波形)。
- 通用二进制协议支持帧头、长度字段、消息类型、数值字段和 CRC，详细步骤见[使用通用二进制协议](#26-使用通用二进制协议)。
- Modbus RTU、ASCII 和 TCP 支持主动轮询功能码 03/04，并把寄存器转换成 `reg<地址>` 通道，详细步骤见[使用 Modbus 寄存器波形](#25-使用-modbus-寄存器波形)。
- 文本模式下每行数据应包含一次完整采样并以换行结束；解析预览成功后再点击 `应用解析`。

滑块默认在松手时发送，也可以启用连续发送；连续发送固定按 100ms 节流，避免拖动时占满串口。控制面板使用自由画布，组件位置与尺寸按连续坐标保存；画布会随组件向右或向下扩展，窗口较小时可滚动查看。

摇杆使用 `{x}`、`{y}` 作为坐标占位符，可分别配置 X/Y 范围、步长、发送方式和松手回中。连续发送同样按 100ms 节流；开启松手回中后，松手时会发送中心坐标。

参数微调控件使用 `{value}` 作为占位符，可以手动输入数值，也可以通过 `− / +` 按配置的步长调整；点击加减按钮会立即发送，手动输入后按 `Enter` 或点击发送按钮生效。

命令序列控件按从上到下的顺序发送多条命令，每行一条，并可配置命令间隔。空行会被忽略；某条命令发送失败时会停止后续发送，避免设备继续执行不完整流程。

串口日志组件复用主日志视图的虚拟滚动、文本/HEX 显示、复制和导出能力，方向可选 `全部`、`仅接收 RX` 或 `仅发送 TX`。需要收发分栏时可添加两个日志组件并分别选择 RX、TX。

#### 只读组件输入示例

能量槽、接收数值、状态灯、曲线图和 IMU 3D 姿态是只读控件，直接使用波形解析得到的通道数据：

| 组件        | JSON 单行示例                                            | 通道绑定            |
| ----------- | -------------------------------------------------------- | ------------------- |
| 接收数值    | `{"temp":25.3}`                                          | `temp`              |
| 状态灯      | `{"ready":1}`                                            | `ready`             |
| 能量槽      | `{"battery":78}`                                         | `battery`           |
| YT / FFT    | `{"ch1":1.2,"ch2":3.4}`                                  | `ch1`、`ch2`        |
| XY 二维曲线 | `{"x":0.3,"y":0.8}`                                      | X → `x`，Y → `y`    |
| IMU 欧拉角  | `{"roll":10.2,"pitch":-3.1,"yaw":45}`                    | Roll/Pitch/Yaw      |
| IMU 六轴    | `{"ax":0.01,"ay":0.02,"az":1,"gx":0.2,"gy":-0.1,"gz":0}` | `ax/ay/az/gx/gy/gz` |

- 在 `接收通道 key` 中填写波形解析配置里的通道 key，例如 `temp`、`voltage`。
- 能量槽可设置上下限、单位以及横向/纵向显示。
- 接收数值以大号数字显示通道最新值；还没有收到有效数据时显示 `--`。
- 状态灯在通道值大于等于配置阈值时点亮。
- `YT 实时波形` 可绑定最多 6 个 Y 通道，以接收时间作为横轴，并可为当前组件独立选择直线或平滑曲线；`FFT 频谱`可绑定最多 6 个 Y 通道并显示轻量频谱预览。右上角的 `自适应` 可恢复 X/Y 自动范围。
- YT 和 FFT 只显示曲线，不重复提供解析、通道管理和导出工具；卡片右上角可进入完整图形工作台或打开独立窗口。
- `XY 二维曲线` 分别绑定一个 X 通道和一个 Y 通道，用于显示轨迹。
- YT、FFT 和 XY 都可以设置显示点数，范围为最近 10–2000 点。
- `IMU 3D 姿态` 按 X=Roll、Y=Pitch、Z=Yaw 驱动 3D 方块，六个面使用高区分度颜色，相对面采用蓝/橙、绿/品红、紫/黄互补配色；支持 `欧拉角直驱` 和 `原始六轴融合` 两种数据源。
- 设备静止在参考姿态后可点击 `当前姿态归零` 修正安装偏差；点击 `清除归零` 恢复通道原始角度。
- 这些控件不会启动另一套解析逻辑。需要先在串口工作台右侧 `数据` 页配置并应用解析规则。

`欧拉角直驱` 分别绑定 Roll、Pitch、Yaw 三个通道，输入单位可选择角度或弧度。

`原始六轴融合` 分别绑定 `ax/ay/az/gx/gy/gz`：

- 三个加速度轴可使用 g 或 m/s²，但单位必须一致。
- 陀螺仪可选择 °/s 或 rad/s；采样时间戳异常时使用配置的兜底采样率。
- 滤波系数 `α` 越接近 1 越依赖陀螺仪、响应更快；越小越依赖加速度计、长期更稳定，默认 `0.98`。
- 保持设备静止后点击 `静止校准`，会使用最近 200 个采样点估计三轴陀螺仪零偏；也可以在编辑模式手动填写零偏。
- 六轴模式没有磁力计，Yaw 仅由陀螺仪积分，长时间运行会漂移；可通过 `当前姿态归零` 重设当前参考方向。

控制面板直接使用主工作台完整画布。编辑模式的组件属性使用浮动面板，可拖动标题调整位置，点击面板右上角可收起，再通过顶部 `组件属性` 按钮展开。

控制面板会自动保存在本机。点击 `导出` 可以生成 JSON 配置文件，另一台电脑可通过 `导入` 复用相同面板。画布配置格式当前为 `version: 4`，使用自由坐标和连续尺寸；现有 `version: 3` 网格配置会在首次加载或导入时自动迁移。

## 3. 终端视图

终端视图会把串口数据按单会话持续展开，并处理常见的终端字符行为：

- `CR` 回车覆盖
- `LF` 换行
- `Backspace` 退格回写
- ANSI 颜色序列

这让设备 prompt、命令回显和进度更新更接近真实命令行的阅读体验。

## 4. 发送命令

日志视图和终端视图的发送方式不同：

**日志视图**：

1. 在底部发送栏中填写命令
2. 在右侧“收发设置”中分别选择接收显示、接收编码、发送格式、发送编码和换行符
3. 按 `Enter` 或点击 `发送`

发送栏会自动保存最近 20 条发送记录。

### 4.1 发送文件

点击底部发送栏的 `文件`，选择文件后即可发送。发送协议在发送栏左侧的“发送工具”入口中配置，默认使用 `原始字节`：

| 模式      | 用途与限制                                                   |
| --------- | ------------------------------------------------------------ |
| 原始字节  | 文件内容原样发送，不应用文本编码、换行符或 HEX 设置          |
| XMODEM    | 128 字节分块；接收端可通过 `C` 或 `NAK` 选择 CRC 或 Checksum |
| XMODEM-1K | 1024 字节分块并使用 CRC                                      |
| YMODEM    | 发送文件名和文件大小，适合支持 YMODEM 的 Bootloader          |
| ZMODEM    | 发送文件名和文件大小，支持 ZMODEM 握手和接收端续传位置       |

原始字节模式可以设置 `分块字节数` 和 `分块间隔`。设备没有硬件流控且处理速度低于串口速率时，可减小分块或增加间隔；默认值为 1024 字节、0 ms。

使用 X/Y/ZMODEM 前，先让设备或远端程序进入对应接收模式，例如 `rx`、`rb`、`rz`。协议传输期间，应用会暂时接管接收数据以处理 ACK、NAK、CAN 等控制字节，并禁止普通文本和 AI 命令插入；完成、超时或取消后自动恢复普通接收。

注意：

- XMODEM 不携带文件名和精确文件长度，接收端可能保留最后一个分块中的 `0x1A` 填充字节。
- X/Y/ZMODEM 只对本地串口和 TCP 数据源开放；UDP 和模拟数据源只支持原始字节。
- 点击发送进度旁的 `取消` 可终止传输。协议模式会向接收端发送取消控制字节。
- 如果输出日志提示串口写入超时，说明设备或驱动未能在 5 秒内接收当前分块；请减小分块字节数，启用硬件流控，或增加分块间隔。

**终端视图**：

1. 点击终端区域使其获取焦点
2. 直接敲击键盘，字符会立即发送到设备
3. `Enter` 会按当前换行配置发送
4. 粘贴文本时，内容会直接写入串口会话

## 5. 终端快捷交互

终端视图下补充了几项专用交互：

- 方向键：直接发送到设备
- `Enter`：按当前行结束配置发送
- `Ctrl+C`：发送中断控制字节
- `Ctrl+D`：发送 EOF 控制字节
- `Tab` / `Esc`：直接发送控制键
- 粘贴：剪贴板文本会直接写入串口

`本地回显` 默认关闭。如果设备不主动回显命令，可在串口工具栏 `更多` 菜单中手动开启；若设备本身会逐字符回显，保持关闭即可避免 `hheellpp` 这类双写现象。

## 6. 使用建议

- 调试日志较多时，优先使用 `日志` 视图
- 需要和设备命令行持续交互时，切到 `终端` 视图
- 设备本身会回显命令时，建议关闭 `本地回显`，避免双重显示
- 如果需要分析数值流，可点击串口工具栏中的图表视图或分屏视图按钮，并在图表区切换时域 / FFT
- 右侧 `数据` 页是分隔符、JSON、KV、正则或 JustFloat 的唯一解析配置入口；标题栏的 `图表配置` 只管理图形、通道、性能、显示和滤波
- 图表画布使用完整宽度；实时值、通道改名和曲线显隐统一放在图表工具栏的 `通道` 弹窗中
- 图表工具栏提供冻结、清空数据、时域/FFT、统计、通道和导出；缓冲区、可视点数和采样率统一在 `图表配置` 中调整
- `冻结` 只停止画面跟随，后台仍继续解析并缓存；点击 `恢复跟随` 后显示最新数据
- 图表工作台支持弹出为独立窗口，适合一边看串口日志、一边在副屏或单独窗口里盯图；RTT、串口和 BLE 图表窗口可同时运行，互不影响
