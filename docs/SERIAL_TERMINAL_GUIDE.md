# 串口终端视图使用指南

本文档介绍串口工作台中的日志视图和终端视图，以及终端模式下的常用交互方式。

## 1. 视图切换

连接串口并开始接收后，可在串口工具栏的 `日志` / `终端` 按钮之间切换：

- `日志`：适合查看结构化输出、按 `RX/TX` 分流、搜索关键字、切换文本/HEX 和导出日志
- `终端`：适合设备 CLI、Bootloader 命令台、AT 命令和串口 shell 这类持续交互式会话

## 2. 日志视图

日志视图延续原有串口查看能力：

- 支持时间戳显示
- 支持 `RX/TX` 前缀
- 支持收发分屏
- 支持文本 / HEX 模式切换
- 支持颜色标记、波形 / FFT 和日志导出

这些选项统一收在串口工具栏右侧的 `更多` 菜单中。

## 3. 终端视图

终端视图会把串口数据按单会话持续展开，并处理常见的终端字符行为：

- `CR` 回车覆盖
- `LF` 换行
- `Backspace` 退格回写
- ANSI 颜色序列

这让设备 prompt、命令回显和进度更新更接近真实命令行的阅读体验。

## 4. 发送命令

底部发送栏继续作为统一输入入口：

1. 在输入框中填写命令
2. 根据需要选择编码、换行符和 HEX 模式
3. 按 `Enter` 或点击 `发送`

发送栏会自动保存最近 20 条发送记录。

## 5. 终端快捷交互

终端视图下补充了几项专用交互：

- 输入框 `↑ / ↓`：切换本地发送历史
- `Ctrl+C`：发送中断控制字节
- `Ctrl+D`：发送 EOF 控制字节
- `Tab` / `Esc`：可在发送栏 `选项` 面板中点击快捷发送

如果设备不主动回显命令，可在串口工具栏 `更多` 菜单中开启 `本地回显`，让本地终端区同步显示已发送命令。

## 6. 使用建议

- 调试日志较多时，优先使用 `日志` 视图
- 需要和设备命令行持续交互时，切到 `终端` 视图
- 设备本身会回显命令时，建议关闭 `本地回显`，避免双重显示
- 如果需要分析数值流，可继续使用串口工具栏里的 `波形` 或 `FFT`
