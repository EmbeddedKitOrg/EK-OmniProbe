# 触发捕获

等某个条件成立时自动冻结图表，把那一刻**前后**的数据留住。串口、RTT 和蓝牙三个工作台都支持。

## 解决什么问题

图表默认是滚动窗口，只显示最近一段数据。想抓一次瞬时现象——电机堵转的瞬间、某个值越限、偶发的异常帧——就得一直盯着屏幕，而且等你看到时，缓冲区可能早就把它挤掉了。

触发捕获让软件替你盯着。条件一成立就冻结，你回来慢慢看。

**关键是它能留住触发之前的数据。** 因为图表本来就一直在缓存最近的样本，所以"事件发生前那 200 个点"是现成的——这正是排查问题最需要的部分。

## 怎么用

位置：工具栏 → 更多 → **触发捕获**（打开开关后展开设置）

| 设置项 | 说明 |
| --- | --- |
| 通道 | 监视哪一路数据 |
| 条件 | 上升沿 / 下降沿 / 高于电平 / 低于电平 |
| 电平 | 触发阈值，波形上会画一条橙色虚线标出位置 |
| 样本 | 触发点之前保留多少个、之后再采多少个 |
| 模式 | 单次 / 正常 |
| 呈现 | 只显示触发窗口 / 显示全部并标注触发点 |

触发后图表冻结，波形上会有一条橙色竖线标出触发那一刻。看完点**重新武装**继续等下一次。

## 四种触发条件

**上升沿穿越 / 下降沿穿越** —— 数值从电平一侧跨到另一侧的那一刻才算。这意味着：

- 信号一直在电平之上不会触发，必须是"越过去"的动作
- 在电平附近抖动**不会**反复触发，因为每次穿越只成立一次

**高于电平 / 低于电平** —— 只要当前值满足就算。适合"只要超过就抓住"的场景，比如监视温度是否越限。

> 分不清时优先用边沿。大多数"抓某个事件发生的瞬间"的需求，要的都是边沿。

## 两种模式

**单次** —— 触发一次后停住，直到你手动重新武装。适合抓一个明确的、只会发生一次的现象。

**正常** —— 捕获完自动继续等下一次。适合观察反复出现的现象，每次触发都会用新数据覆盖显示。

## 两种呈现方式

**只显示触发窗口** —— 图表只留下触发点前后那一段，聚焦事件本身。这是示波器的做法，适合抓瞬态。

**显示全部并标注触发点** —— 保留整个缓冲区，只在触发位置画标记。适合想看事件在整体趋势里处于什么位置。

两种方式用的是同一份数据，随时可以切换重看。

## 前后置样本数怎么定

先想清楚要看的是**事件之前**还是**之后**：

- 排查"是什么导致了它"——加大前置样本数
- 观察"发生之后怎么变化"——加大后置样本数

两者之和不要超过图表配置里的 `maxDataPoints`（默认 4000），否则前置部分会因为缓冲区不够而取不满。取不满不会报错，只是窗口比设定的短。

## 注意事项

**触发只在图表解析启用时工作。** 没有解析出数值就无从判断条件。

**改了解析配置后要检查触发通道。** 通道列表变化后，原来选的触发通道可能已经不存在，面板会给出提示。

**清空图表会同时复位触发状态。** 这是有意的——否则残留的"已触发"状态会让后续数据永远不再触发，而且很难看出原因。

**捕获后图表处于冻结状态**，与手动暂停是同一个机制。此时数据仍在后台接收，只是不刷新显示。

## 配合其他功能

- 触发捕获到的数据可以直接[导出为 CSV 或 PNG](DATA_FORMAT_GUIDE.md)
- 想反复分析同一次捕获，用[会话录制](SESSION_RECORD_GUIDE.md)把原始数据存下来，之后能换不同解析或滤波配置重放
- 触发判断作用在**滤波后**的数值上，也就是你在图上看到的那条曲线。这样设电平时所见即所得；代价是[滤波配置](MATLAB_FILTER_GUIDE.md)会影响触发时机——滤波器的延迟会让触发相应推迟。想按原始信号触发就先关掉滤波
