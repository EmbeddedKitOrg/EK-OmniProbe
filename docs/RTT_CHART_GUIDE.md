# RTT 图表与波形功能指南

## 功能概述

当前版本的 RTT 图表已经升级为“业务图表 + 调试波形”双模式，适合日志可视化，也适合实时调试数值流。

支持能力：

- **视图模式**
  - 仅文本
  - 仅图表
  - 分屏显示
- **解析方式**
  - 自动模式
  - 分隔符
  - 正则表达式
  - JSON
- **图表类型**
  - 波形示波器
  - FFT 频谱
  - 折线图
  - 柱状图
  - 散点图
  - XY 散点图
- **实时交互**
  - 左键拖拽平移
  - 滚轮缩放 Y 轴
  - `Shift + 滚轮` 缩放 X 轴
  - 右键或点击“自适应”重置视图
  - 鼠标悬停查看当前点
  - CSV 导出
- **工作台结构**
  - 中间主图优先展示
  - 单条工具栏提供冻结、清空、时域/FFT、统计、通道和导出
  - `通道` 弹窗可查看实时值、修改名称和控制曲线显隐
  - 波形底部控制栏显示采样、缓存和通道状态，并提供 X 轴缩放条
  - 整个图表工作台可弹出为独立窗口，方便在副屏或单独窗口里持续观察
  - RTT、串口和 BLE 独立窗口可同时运行；切换主工作台不会自动收回，控制操作按数据源隔离

## 推荐用法

### 适合用波形示波器的场景

- RTT 输出连续采样值，例如电压、电流、速度、角度
- 想看最近一段时间的波形变化趋势
- 想快速切换到 FFT 查看主频、谐波和噪声分量

### 适合用普通图表的场景

- 只需要看趋势，不需要频谱分析
- 数据是结构化报文或状态数据
- 需要 XY 关系图而不是时间轴波形

## 快速开始

### 1. 启用图表

1. 连接 RTT 并启动采集
2. 打开工具栏的 `更多`，点击 `智能启用` 或打开 `图表配置`。如果接收缓冲区已有数据且通道为空，配置窗口会先按当前解析模式预建通道；`自动` 模式会同时识别数据格式
3. 建议把图表类型选为 `波形示波器`
4. 保存配置
5. 切换到 `仅图表` 或 `分屏显示`
6. 如果你已经明确要看时域或频域，也可以从工具栏的 `更多` 中点击 `波形` / `FFT`
7. 点击图表工具栏的 `通道`，可查看当前解析字段并把字段加入曲线
8. 在波形底部拖动 X 轴缩放条调整可视范围；缓冲区上限、可视点数和采样率在 `图表配置 → 性能与采样` 中精确输入

### 2. 用“智能启用”自动识别

当 RTT 已经收到几行数值数据后：

1. 打开工具栏的 `更多`，点击 `智能启用`
2. 程序会自动判断是单值、CSV、XY 还是 JSON
3. 对于时间序列数据，默认会自动切到 `波形示波器`

### 3. 时域 / 频域切换

现在有两种进入方式：

- 方式一：从 RTT / 串口 / BLE 工具栏的 `更多` 中点击 `波形` 或 `FFT`
- 方式二：当图表类型为 `波形示波器` 时，在图表工具栏里继续切换 `时域 / FFT`

`更多` 中当前打开的 `波形` 或 `FFT` 会保持点亮；再次点击已点亮的按钮会收起图表并切回仅文本。收起只改变布局，数据仍在后台解析和缓存；如需停止解析，请关闭图表配置中的总开关。

当图表类型为 `波形示波器` 时，图表工具栏会出现：

- `时域`：显示按采样率重建的等间隔时域波形
- `FFT`：显示频谱结果
- `冻结`：保留当前画面用于观察，后台继续解析和缓存；点击 `恢复跟随` 后追上最新数据

说明：

- 采样率优先使用配置中的 `采样率 (Hz)`
- 如果填写为 `0`，程序会按实际时间戳自动估算
- 时域波形会按样本等间隔重建横轴，避免串口 / RTT 批量到达时出现竖线、折返和乱跳
- FFT 默认使用最近的 `1024` 个点，可在配置里调整

## 配置示例

### 示例 1：单个数值波形

固件输出：

```c
printf("%.3f\n", voltage);
```

推荐配置：

- 解析模式：自动 或 分隔符
- 图表类型：波形示波器
- 字段：`value`
- 系列：`value -> 电压`

### 示例 2：CSV 多通道波形

固件输出：

```c
printf("%.3f,%.3f,%.3f\n", ia, ib, ic);
```

推荐配置：

- 解析模式：分隔符
- 分隔符：`,`
- 字段：
  - `0 -> ia`
  - `1 -> ib`
  - `2 -> ic`
- 图表类型：波形示波器
- 系列：
  - `ia -> A相`
  - `ib -> B相`
  - `ic -> C相`

### 示例 3：JSON 结构化输出

固件输出：

```json
{ "temp": 25.5, "rpm": 1450, "current": 2.18 }
```

推荐配置：

- 解析模式：JSON
- 图表类型：波形示波器 或 折线图
- 系列：
  - `temp -> 温度`
  - `rpm -> 转速`
  - `current -> 电流`

### 示例 4：XY 数据

固件输出：

```c
printf("%.2f,%.2f\n", angle, torque);
```

推荐配置：

- 解析模式：分隔符
- 图表类型：XY 散点图
- X 轴字段：`x`
- 系列：`y -> 扭矩`

## 波形交互说明

在 `波形示波器` 模式下：

- **左键拖拽**：平移时间轴或频谱视图
- **滚轮**：缩放 Y 轴
- **Shift + 滚轮**：缩放 X 轴
- **底部控制栏**：集中显示采样间隔、缓冲点数、绘制点数、每格时间或频率、通道颜色和滤波状态
- **X 轴缩放条**：拖动底部进度条缩放时域或频域的 X 轴，与 `Shift + 滚轮`作用相同
- **采样 Auto**：恢复按数据到达时间自动估算采样率
- **右键 / 自适应**：恢复 X/Y 自动范围；处于自动范围时按钮保持点亮
- **悬停**：查看当前时刻或当前频点的数值
- **连接方式**：在图表配置的“显示选项”中选择直线连接或平滑曲线；仅影响时域波形的绘制效果

在 `FFT` 模式下：

- X 轴显示频率（Hz）
- Y 轴显示幅度（dB）；Hann 窗已做幅值补偿，单位正弦在频点对齐时峰值约为 `0 dB`
- 多个系列会叠加显示，便于比较频谱差异

## 配置项说明

### 基础

- **启用图表功能**：总开关
- **解析模式**：自动 / 正则 / 分隔符 / JSON / KV；串口还支持 JustFloat / VOFA RawData
- **图表类型**：波形示波器、折线图、柱状图、散点图、XY 散点图

### 采样与缓存

- **最大数据点数**：缓存长度，建议 `1000 ~ 4000`
- **可视点数**：限制单次绘制的点数，`0` 表示跟随当前缓存自动显示
- **刷新间隔**：界面刷新频率，默认 `33ms`
- **采样率 (Hz)**：FFT 频率轴使用，`0` 表示自动估算
- **时域波形横轴**：优先使用采样率重建等间隔时间轴；未填写时会按最近一段数据自动估算
- **FFT 窗口大小**：默认 `1024`
- **波形 / FFT 入口**：位于工具栏的 `更多` 菜单，会自动切到波形示波器并切换观察域

### 显示

- **波形连接方式**：`直线连接` 保留采样点之间的线性变化，`平滑曲线` 让趋势更易观察；默认使用直线连接
- 平滑只改变屏幕上的连接方式，不修改原始采样点和悬停数值；FFT 频谱始终使用直线连接

### 通道

- 已有通道不会被缓冲区自动识别结果覆盖。通道为空时，打开配置窗口会读取最近的接收数据：`自动` 模式自动选择格式，手动选择的模式则保持不变并按该模式提取字段
- 为每个字段设置：
  - 键名
  - 显示名称
  - 单位
  - 颜色
  - 是否可见
- 右侧字段栏会优先显示当前解析到的字段；尚未入图的字段可先点击 `加入`，再参与曲线显示

## 常见问题

### 图表没数据

检查：

1. 到右侧 `数据` 页粘贴一条真实样本，确认预览识别出数值通道并点击 `应用解析`
2. 是否启用了图表功能
3. 是否已经收到与样本格式匹配的数据
4. 系列 `key` 是否和字段名一致
5. 解析统计里的“失败”是否持续增加

### FFT 看起来不对

检查：

1. 采样率是否正确
2. 数据是否足够稳定
3. FFT 窗口大小是否合适
4. 数据间隔是否过于抖动

### 图表卡顿

建议：

1. 把最大数据点数调低到 `1000 ~ 2000`
2. 降低固件输出频率
3. 关闭不需要的系列
4. 冻结图表后再观察当前画面

## 当前限制

- 目前导出仍为 CSV，不包含图片导出
- FFT 采样率自动估算依赖时间戳，极端不稳定数据会影响频率轴精度
- Live Watch 变量采样能力尚未并入当前图表链路，本次升级重点是 RTT/串口波形与 FFT
