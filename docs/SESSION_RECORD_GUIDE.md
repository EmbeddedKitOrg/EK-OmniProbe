# 采集会话录制与回放

把一段采集完整录下来存成文件，之后重新载入解析。串口、RTT 和蓝牙三个工作台都支持。

## 解决什么问题

导出 TXT / CSV / PNG 都是单向的，导出后无法再改变解析方式。于是：

- 想对比两组滤波参数，只能把现象**重新复现一遍**
- 现场抓到的异常，没法原样交给别人分析
- 改完解析配置想验证，得重新连设备

录制保存的是**原始字节流**而不是解析后的数值，因此回放时可以换一套解析或滤波配置，对同一份数据重新跑一遍。

## 怎么用

**录制**：工具栏 → 更多 → 工作流 → **录制会话**。按钮变红表示正在录制，此时收到的原始字节都会被留存。

**保存**：再次点击（此时显示**停止并保存**）→ 选择保存位置。文件扩展名是 `.ekrec`。

**回放**：更多 → 工作流 → **回放会话** → 选择 `.ekrec` 文件。图表会先清空，然后填入回放解析出的数据。

> 回放前会清空当前图表，避免回放数据与实时数据混在一起。日志区的历史内容不受影响。

## 文件里存了什么

| 内容 | 用途 |
| --- | --- |
| 原始字节流 | 回放时重新走完整的分帧、解析、滤波链路 |
| 每块的相对时间 | 还原数据到达的时序 |
| RTT 通道号 | 回放时按通道分别拼帧，避免跨通道串数据 |
| 录制时的图表配置 | 回放默认沿用，含解析模式、通道、滤波参数 |
| 接收分帧设置 | 仅串口，回放时还原断行方式 |

文件是 NDJSON 文本格式（每行一条 JSON），可以用文本编辑器打开查看，首行即为上述配置信息。

## 换配置回放

这是录制功能最主要的用途。载入会话后，直接修改图表配置（解析模式、通道、滤波参数）即可——原始字节不受影响，重新解析就能看到新配置下的结果。

典型场景：

- **调滤波参数**：录一段带噪声的真实信号，反复试不同截止频率，每次都作用在完全相同的数据上
- **验证解析配置**：设备不在手边时，用之前录的数据验证正则或分隔符配置是否正确
- **回归对照**：升级固件后录一段新数据，与旧版本的录制文件对比

## 注意事项

**只录接收方向。** 发出去的内容不是设备上报的数据，不参与录制。

**容量上限 32 MB。** 超出后停止追加并在日志中提示「录制超出容量上限」，已录部分仍可正常保存和回放。高速数据下这个上限很快会到，建议只录关注的那一段。

**录制不影响实时显示。** 录制期间图表、日志、终端照常工作。

**跨工作台回放会提示。** 例如把 RTT 录的文件在串口工作台回放，会提示解析配置可能不适用——文件仍会回放，但需自行确认配置是否合适。
